# הוספה והסרה של מחשבים שמורשים להתחבר לשרת

כל מחשב מקבל מפתח משלו. כך, אם מחשב נגנב, מבטלים רק את המפתח שלו.

## הוספת מחשב חדש

### 1. יצירת מפתח במחשב החדש
המשתמש מריץ ב-PowerShell **במחשב החדש**. הפקודה שואלת על סיסמה למפתח:
```powershell
ssh-keygen -t ed25519 -C "<שם-המחשב>" -f "$env:USERPROFILE\.ssh\assistant_server"
Get-Content "$env:USERPROFILE\.ssh\assistant_server.pub"
```
⚠️ לא לדרוס מפתח `id_ed25519` קיים.

המפתח הציבורי (השורה שמתחילה ב-`ssh-ed25519`) לא סודי. מותר להעתיק אותו, לשלוח אותו במייל, או להדביק אותו בצ'אט.

### 2. הוספה לשרת
יש שלוש דרכים, לפי מה שזמין:

**א. מסשן שכבר מחובר לשרת** (`ssh assistant` עובד במחשב הנוכחי):
```bash
ssh assistant 'grep -qxF "<המפתח-הציבורי>" ~/.ssh/authorized_keys || echo "<המפתח-הציבורי>" >> ~/.ssh/authorized_keys'
```

**ב. מהמחשב הישן**, אם הוא עדיין מחובר: המשתמש מריץ שם את אותה פקודה, עם `ssh -i <המפתח-הישן> ubuntu@<כתובת>`.

**ג. אף מחשב לא מחובר:** משתמשים בלוח הבקרה של הענן.
- ב-Oracle: Instance ← **Console connection** (חיבור קונסולה), או יצירת השרת מחדש עם המפתח החדש.
- ב-Hetzner: **Rescue** (מצב חילוץ), או **Reset root password**.
- זו דרך מסורבלת. לפני שמתחילים, תסביר את הצעדים למשתמש ותקבל אישור.

### 3. הגדרה ובדיקה במחשב החדש
- תוסיף את `Host assistant` ל-`%USERPROFILE%\.ssh\config` ותפעיל את הסוכן (ssh-agent), לפי הסקיל `deploy`, שלב 3.
- בדיקה: `ssh -o BatchMode=yes assistant "echo ok"`.

## הסרת מחשב
1. **רשימת המפתחות:**
   ```bash
   ssh assistant "cat -n ~/.ssh/authorized_keys"
   ```
   כל מפתח מזוהה לפי ההערה בסוף השורה, למשל `oracle-assistant` או שם המחשב.
2. תציג למשתמש את הרשימה, ותקבל אישור **על השורה המדויקת** שמוחקים.
3. ⚠️ **לפני המחיקה:** תוודא שהמחשב הנוכחי משתמש במפתח אחר. אחרת, המחיקה תנעל אותך מחוץ לשרת.
4. מחיקה של השורה שאושרה, לפי מספר השורה:
   ```bash
   ssh assistant "sed -i '<מספר>d' ~/.ssh/authorized_keys"
   ```
5. בדיקה שהחיבור מהמחשב הנוכחי עדיין עובד.

אחרי כל הוספה או הסרה, תעדכן ב-`CLAUDE.md`, בסעיף "מצב ההתקנה", אילו מחשבים מורשים.
